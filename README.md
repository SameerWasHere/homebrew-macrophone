# Homebrew tap for Macrophone

[Macrophone](https://sameer.us/macrophone) — steer your Mac from your iPhone, by voice. Free and open
source ([source](https://github.com/SameerWasHere/macrophone)).

```
brew install --cask sameerwashere/macrophone/macrophone
```

This installs the same signed, notarized download as the website. Macrophone updates itself;
`brew upgrade --cask macrophone` works too. The iPhone app is on the App Store.

The cask is updated by Macrophone's release script (`Mac/scripts/release.sh`).
